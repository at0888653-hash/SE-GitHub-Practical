# Software Engineering GitHub Practical

## Objective

To demonstrate version control and collaboration practices using GitHub.

## Project Description

This practical demonstrates how GitHub can be used to manage project files,
track changes, create branches, and collaborate using pull requests.

## GitHub Workflow

1. Create a repository
2. Add project files
3. Commit changes
4. Create a feature branch
5. Make changes
6. Create a pull request
7. Merge the changes
8. View commit history
